Зелёный день означает, что все участники свободны. Ручные изменения сохраняются отдельно для каждой даты.

Новый участник

Указанная дата считается первым рабочим днём цикла. Например, для графика 2/2 после двух рабочих дней следуют два выходных.
Числа относятся только к месяцу, выбранному сейчас. При просмотре другого месяца этот пользователь будет считаться свободным, пока вы не зададите даты для него.

Поделиться графиком

Каждый участник записывается с новой строки. Можно скопировать данные или вставить чужой график.
Формат: Имя/график/дата начала
Например: pasha/2-2/21.11.2026

Для ручного графика: ivan/manual@2026-11/3,8,14
